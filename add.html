Add new work

Three steps, about two minutes. New work appears at the top of its folder on the site about a minute after you save.

1

Upload the file to GitHub

Open the right folder, choose Add file → Upload files, pick your photo or video, then press Commit changes. Note the exact file name.

Upload a photo ↗Upload a video ↗
  • Photos: JPG, under 3 MB (about 2000px on the long side is perfect).
  • Videos: MP4, under 25 MB (export 1080p or 720p). Optional: also upload a cover image (JPG) for the film.
  • Use simple file names with no spaces, e.g. bonalu-2026.jpg, wedding-teaser.mp4.
  • On a phone, open GitHub in your browser's Desktop site mode to see "Upload files".
